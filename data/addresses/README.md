Addresses data
===

The address files here are sampled from https://usps.biglocalnews.org.

## Different samples

### `original-sample-10pct-by-county`

Each file represents a 10% random sample of the entire county (Caledonia, Lamoille, Orleans, Washington).

### `100pct`

Five counties (Caledonia, Lamoille, Orleans, Washington, and Essex), with 100% of known addresses.

### `four-county-2500-addresses.csv`

This is 2,500 addresses sampled randomly across all four counties of interest (Caledonia, Lamoille, Orleans, Washington).
